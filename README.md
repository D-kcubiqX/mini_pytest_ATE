# mini_pytest_ATE

## ATE (Adaptive Transport Engine)

Моя попытка сделать выбор транспорта не методом перебора, а с помощью системы баллов.

**По умному**: "Песочница для тестирования логики выбора сетевых протоколов."

**По простому**: "Меня заебало вручную переключаться между VPN, клиентами и протоколами, поэтому я решил проверить, можно ли хотя бы часть этого выбора автоматизировать."

---
# ⚠ !!!Для невнимательных!!! ⚠

Это **экспериментальный прототип.** 

Цель — **тестировать логики выбора транспорта.**

Это **НЕ VPN**.

Это **НЕ VPN-клиент**.

Это **НЕ готовый продукт**.

Если программа не умеет делать то, что умеют обходняки, то это ожидаемое поведение.

**Я предупреждал.**
